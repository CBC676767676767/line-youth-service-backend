# 本機 OCR 資產

- Tesseract.js 6.0.1：worker.min.js。
- Tesseract.js-core 6.1.2：LSTM及SIMD LSTM的WebAssembly引擎。
- eng / chi_tra：Tesseract官方tessdata_fast英文與繁體中文模型。
- 檔案來源URL、SHA-256與版本見manifest.json；授權文件已隨檔附上。

模型由本站同源載入，不使用第三方CDN。圖片在瀏覽器運算，不上傳；OCR候選可能錯誤，不驗證身分、真偽、付款或補助資格。繁中／英文模型已驗證可執行，尚未對政府案件資料評估準確率。

官方專案：https://github.com/naptha/tesseract.js
模型：https://github.com/tesseract-ocr/tessdata_fast
