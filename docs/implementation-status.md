# 系統實作狀態與驗證邊界

更新日期：2026-09-19。本文件區分已實作、本機驗證與待外部驗證；程式存在或測試通過不代表政府正式收件、LINE 真機接通或雲端部署完成。

## 已實作的流程

| 領域 | 目前能力 | 邊界 |
| --- | --- | --- |
| 民眾／承辦入口 | React／TypeScript 雙入口，既有信箱 OTP、Cookie、CSRF、承辦密碼與 TOTP；案件摘要及補正待辦使用後端 API | 登入不代表實名、戶籍或補助資格查證 |
| 行政預檢 | 後端確定性規則引擎、工具／方案／通路分類、日期自查、Decimal 條件式試算、逐月交易與個人化備件 | 未知項目保留人工確認；不使用 LLM 核定，不做文件真偽查證 |
| 規則來源 | `precheck-hsinchu-115.json` 保存 `hsinchu_ai_2026 / public_2026_09_19` 公開來源快照；合成 demo 另存 | `agency_approved=false`；公開來源查核與機關確認系統規格不同，即時經費未知 |
| 保存與差異 | 登入後驗權、CSRF、ETag、冪等重試，後端重算並保存不可變快照；比較新增、解除、待確認及失去確認的項目 | 預檢保存不正式送件，不變更核定或財務狀態；既存快照不隨後續案件狀態改寫 |
| 本機申請紀錄 | 依當前權限檢查同方案既有紀錄，區分草稿、送出、撤回、未核准與核定；另外回傳目前可見的紀錄檢查 | 目前紀錄與歷史快照分開；核定不等於已撥款，不宣稱排除跨機關重複補助 |
| LINE 對話 | 六格選單、七個文字指令、四步工具與交易選擇、桌機 Flex／手機快速回覆、獨立規則卡、低隱私結果摘要及安全練習 | 不在聊天收取生日、證件、帳號、金額或附件；安全練習不改變行政結果，未串接真人客服 |
| LINE 傳送 | 明確啟用的 live reply adapter，沿用驗簽、destination、事件去重及有期限的 reply token；API 生命週期管理專用回覆 worker | HTTP 模擬已驗證；本輪未對真實 LINE 使用者發訊息，`API_ACCEPTED` 不代表送達或已讀 |
| 既有案件與附件 | 草稿、正式提交、不可變回執、補正修訂／接受／退回、審查、核定；附件私有儲存、隔離掃描與逐次下載驗權 | 開發掃描器不是防毒；沒有新增政府、戶政、銀行或出納介接 |

匿名預檢的完整填答只留在頁面記憶體；只有登入保存才建立案件快照。行政結果與資安提醒分開保存及呈現。原有附件上傳、收件時間與文件版本規則維持不變，不因預檢或聊天點選而接受補正。

聊天交接碼只帶入非敏感購買選項。尚未保存的結果明示「尚未保存」並導回完整預檢；只有登入保存交易成功後，才顯示「已保存預檢（未正式送件）」。已保存連結使用不透明 token，結果查詢仍要求登入、相同擁有人及逐案權限；網址與聊天不放案件 ID。過期、重新開始、規則改版或新一次評估不能沿用舊的保存標示。

互動模擬器預設關閉，不出現在一般服務入口；僅保留可明確啟用的 development/test 離線測試用途。一般本機啟動腳本同時停用 live sender 與模擬器。

本輪沒有建立 Git commit 或執行 GitHub push。既有遠端歷史不作為本輪交付或驗證證據。金鑰、private profile、驗證郵件、案件資料與附件均不屬於交付文件。

正式使用前仍需機關確認規則歧義、通知與工作日曆、保存政策、權限流程及維運要求；未宣稱完成負載、正式無障礙、備份還原或高可用驗收。規則與待確認事項見 [公開來源](precheck-policy-sources.md)及[待確認清單](precheck-pending-confirmations.md)。
