# 115 年度新竹市 AI 補助規則來源

查核日：2026-09-19。本版本以[官方申辦須知](https://dgservice.hccg.gov.tw/serviceNotice.do?id=1323&rule=guest)與[官方更新公告轉知](https://rdec.tainan.gov.tw/News_Content.aspx?n=17460&s=8831950&sms=17958)的網頁文字為規則來源，與使用者提供的公開條件快照核對，未發現須另建版本的條件差異。本輪沒有主張已閱讀所有申請附件或完成機關確認；網站更新日與剩餘經費未確認。

| 項目 | 公告條件摘要 |
| --- | --- |
| 設籍／出生日期 | 新竹市；1985-04-03 至 2010-04-02，含首尾 |
| 購買期間 | 2026-04-02 至 2026-10-31 |
| 受理截止 | 2026-11-30，可能因額滿或經費用罄提前停止 |
| 一般青年 | 購買額 50%，最多 3,000 元 |
| 特定對象／文化語言保存者 | 90%，最多 6,000 元；須具相應證明 |
| 交易方式 | 直接向官方網站購買；集合平台、代購、額外預付額度列為限制 |

購買日期與受理日期是不同條件，保存預檢不保留期限。工具名稱只是公告示例，不是全方案白名單；未收錄方案、App 商店及不明通路均須確認。金額採 Decimal 條件式試算，明示身分及費用均尚未核對，不能當成核定金額。

網頁中的連續月份累積與跨月文字須釐清。代付主文與審核段落的關係範圍不同，先準備共同切結與關係資料，由承辦確認；非信用卡付款佐證、月末與假日期限處理等均列入[待確認清單](precheck-pending-confirmations.md)。

`app/data/precheck-hsinchu-115.json` 載入 `hsinchu_ai_2026 / public_2026_09_19` 公開來源快照；`agency_approved=false`、`usage=advisory_precheck`、`automatic_approval_enabled=false`。已核對公開來源允許明確條件產生提示，只有未確認情境才轉人工；不是機關審查過的系統規格。未填入未核對的方案或網域，也未猜測月份期限。合成示範另放 `precheck-demo.json`。

維護時先核對公告、方案／網域及歧義，再由有權人員填寫確認資訊、改版並執行測試；不可只改 `status` 來消除待確認。每次保存均記錄完整設定及雜湊，即使維護者漏改版本也可識別設定差異。
